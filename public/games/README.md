# Game logo assets

The optimizer currently shows **monogram badges** (initials in each game's brand colour,
see `components/games/GameBadge.tsx`). No official logos are bundled.

To add a real logo:

1. Get it from the publisher's official press kit / media page, and confirm the licence allows
   use in a third-party app like this one. Keep a note of the source URL and licence here.
2. Save it as `public/games/<game-id>.svg` (or `.png`, square, at least 128×128).
3. Render it in `GameBadge` for that game.

Do not hotlink or scrape logos from game websites or CDNs, and don't add a third-party
logo/icon pack without checking with the project owner first.
